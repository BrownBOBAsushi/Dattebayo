# Multiplayer Fireball artwork

`fireball-frame.png` and `fireball-frame-02.png` were generated on 2026-09-13 with the built-in image-generation tool for the approved multiplayer Fireball effect. They are two distinct RGBA flame poses; browser code animates them and supplies the lighting, embers, and impact timing. The original generated pixels and alpha are preserved. Neither contains character artwork or UI text. Two intermediate edits were rejected because they contained a baked checkerboard; only the transparent outputs are included here.

## Frame 1 generation prompt

Create a production game VFX asset: a transparent FIREBALL CAST border overlay, not a screenshot or mockup. Very wide horizontal 3:1 composition, ideally 1536 by 512. The center must be completely transparent with true alpha, suitable for placing over an existing game arena. Draw vivid, finely detailed arcade-anime fire only around the outer perimeter: flame tongues climbing the left and right edges, thinner licking fire along the top edge, a slightly fuller rising flame bed across the bottom edge, sparse glowing embers near the perimeter. Keep at least the central 78 percent of width and central 65 percent of height entirely clear. Rich deep-orange bases, bright tangerine and golden yellow flame cores, restrained cream highlights, elegant curved flame silhouettes with crisp stepped pixel-art edges appropriate to a detailed 2D ninja arcade game. Intense and cinematic but readable; the flame border must never form a solid rectangular panel. Flames should feel organic and asymmetrical. All glow must fade naturally to transparent alpha. No black background, no white background, no baked checkerboard, no sky, no landscape, no characters, no central fireball, no text, no UI, no logos, no watermark, no metal or solid decorative frame. Single isolated finished flame border asset with true transparent background; do not put it on a sample background.

## Frame 2 generation prompt

Generate one NEW game VFX asset with a TRUE TRANSPARENT BACKGROUND (alpha channel). This is an isolated flame-border overlay for animation, not an illustration of a transparent image. Canvas very wide 3:1, ideally 2172x724. Only the outer perimeter contains fire; the central 78% width and central 60% height form a large empty transparent opening. Draw bright golden-orange arcade-anime flames with crisp detailed contours: a broad but shallow flame bed hugs the bottom; several thin long tongues curl upward and bend to the right; the bottom centre has two narrow hooked tongues instead of one broad plume. Tall left and right border tongues lean and curl upward, with a few detached small embers drifting higher near those edges. The top border is thin with separated flowing flame ribbons. Border thickness approximately 10% width on each side, 9% height at top, 23% at bottom; central gameplay opening stays clear. Intense gold/cream flame cores with orange and red edges, fairly even brightness across edges, subtle alpha glow. The shape should feel like the next animation pose of a living fire border. Keep fire right at outer edges with no solid decorative frame. The output must be RGBA with transparent empty pixels, including all gaps between tongues and every pixel in the central opening. Do not paint a transparency preview pattern: absolutely NO checkerboard. No background color, no grey or white or black central field, no characters, no text, no scenery, no UI. One standalone game border with a real transparent background. Render the fire only; leave the rest empty.
